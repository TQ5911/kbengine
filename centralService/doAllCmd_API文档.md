# API文档：/doAllCmd

## 端点
```
POST /doAllCmd
```

## CORS支持
- **允许来源**: `*` (所有来源)
- **允许方法**: `POST`, `OPTIONS` (支持预检请求)
- **允许头**: `Content-Type`

## 请求体
请求需设置 `Content-Type: application/json` 头，请求体为 JSON 对象，结构如下：

| 字段名      | 类型    | 必填 | 描述                                                                 |
|-------------|---------|------|----------------------------------------------------------------------|
| `Partition` | int32   | 否   | 分区ID。**此端点忽略该字段**（默认处理所有服务器）                     |
| `Command`   | string  | 是   | skuId操作命令类型。必须是服务器支持的skuId设置命令                     |
| `Args`      | string  | 是   | 十六进制编码字符串，格式为 `skuId  proportion`。详情见 [参数格式](#参数格式) |
| `SendTime`  | uint32  | 否   | 发送时间（未提供则由服务器自动生成）。格式：YYYYMMDD（例如20251203表示2025/12/03） |
| `Seqid`     | uint64  | 否   | 序列ID（如果 `SerialNo` 为空则用作 `SerialNo`）                       |
| `SerialNo`  | string  | 否   | 用于幂等性的序列号（**推荐优先使用，确保请求唯一性**）                  |

### 参数格式
`Args` 字段必须是**十六进制编码**的字符串，明文格式如下（两个空格分隔两个参数）：
```
{skuId}  {proportion}
```

#### 比例参数格式
比例使用 `{分母}:{分子}` 格式（例如 `100:200` 表示 200/100 = 2.0）。

### 请求示例
```json
{
  "Partition": 0,
  "Command": "setSkuId",
  "Args": "313233343520203130303a323030",
  "SendTime": 20251203,
  "SerialNo": "doAllCmd-20251203-001"
}
```

示例说明：
- `Args` 解码后为：`12345  100:200`
  - `skuId`: `12345`
  - 比例: `200/100 = 2.0`

## 响应
服务器返回 JSON 响应，结构如下：

### 响应结构
| 字段名      | 类型                  | 描述                                                                 |
|-------------|-----------------------|----------------------------------------------------------------------|
| `result`    | int32                 | 结果码（0 表示成功，负值表示错误）                                    |
| `msg`       | string                | 结果消息（成功/错误描述）                                             |
| `body`      | map[string]interface{}| 附加数据（**此端点始终为 `null`**）                                    |

### 响应示例
#### 成功响应
```json
{
  "result": 0,
  "msg": "success",
  "body": null
}
```

#### 错误响应（内部服务器错误）
```json
{
  "result": -215,
  "msg": "add cache error",
  "body": null
}
```

#### 错误响应（速率限制超过）
```
HTTP 状态码: 406
```
(无响应体；速率限制超过时服务器直接返回状态 406)

## 关键约束和注意事项
1. **速率限制**: 端点内置速率限制，超过限制将返回状态 406。
2. **请求大小限制**: 请求体限制为 **512 字节**。
3. **超时**: 服务器处理所有服务器请求时超时时间为 30 秒。
4. **幂等性**: 使用 `SerialNo` 确保幂等性（相同 `SerialNo` 将返回相同响应而不重新处理）。
5. **范围**: 此端点**仅支持 skuId 设置操作**。
6. **十六进制编码**: 确保 `Args` 字段正确进行十六进制编码（例如，在 Go 中使用 `hex.EncodeToString()`，或其他语言的等效方法）。

| -214   | 参数长度超过限制         |
