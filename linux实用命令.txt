传送文件相关命令

	#从服务器 / 虚拟机向本地终端（物理机）传输文件的工具，属于 lrzsz 工具集的一部，特别适合没有共享文件夹、只想快速传小文件的场景
	sudo apt install lrzsz
	sz = 「Linux → 本地」传文件；rz = 「本地 → Linux」传文件


	在「本地 ↔ 远程服务器」、「远程服务器 A ↔ 远程服务器 B」之间，安全的传输文件 / 文件夹
	scp命令
	在当前windows桌面的powerShell下输入命令
	上传到虚拟机如 scp C:\Users\Administrator\Desktop\kbengine.rar fengyan@192.168.10.172:/home/fengyan
	从虚拟机下载如 scp fengyan@192.168.10.172:/home/fengyan/kbengine.rar "C:\Users\Administrator\Desktop\"
	如果是文件夹则加 scp 后跟 -r 参数

	也可以再虚拟机里
	有的可以使用如下
	scp -o StrictHostKeyChecking=no -o UserKnownHostsFile=/dev/null fengyan@192.168.10.172:/home/fengyan/kbengine.rar /c/Users/Administrator/Desktop
	有的如下会下载到  C:\Users\Administrator\Recent
	scp -o StrictHostKeyChecking=no -o UserKnownHostsFile=/dev/null fengyan@192.168.10.172:/home/fengyan/kbengine.rar ~/

虚拟机共享目录后 服务器里需要手动挂载
# 创建挂载点（不存在时）
sudo mkdir -p /mnt/hgfs
# 临时挂载所有共享（允许普通用户访问）
sudo vmhgfs-fuse .host:/ /mnt/hgfs -o allow_other
# 查看结果
ls /mnt/hgfs
# 设置开机自动挂载（永久生效）
sudo vim /etc/fstab
# 添加以下行（末尾换行），共享名替换为实际名称
.host:/ /mnt/hgfs fuse.vmhgfs-fuse allow_other,defaults 0 0
# 生效配置
sudo mount -a

安装jenkins时
通过官方源 GPG秘钥一直提示 秘钥有问题
最后通过下载
直接下载 Jenkins 的 .deb 安装包手动安装，绕过 apt 源的签名验证环节

wget https://pkg.jenkins.io/debian-stable/binary/jenkins_2.479.1_all.deb

# 安装下载的 deb 包，自动处理依赖
sudo dpkg -i jenkins_2.479.1_all.deb

# 若出现依赖缺失，执行以下命令修复
sudo apt -f install -y

# 启动服务
sudo systemctl start jenkins

# 设置开机自启
sudo systemctl enable jenkins

# 检查服务状态
sudo systemctl status jenkins

#开放 8080 端口
sudo ufw allow 8080/tcp && sudo ufw reload
# 查看防火墙状态（确认 8080 端口已开放）
sudo ufw status

# 获取初始管理员密码
sudo cat /var/lib/jenkins/secrets/initialAdminPassword

sudo chmod -R 775 /home/fengyan/jenkins
